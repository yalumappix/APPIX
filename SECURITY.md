# Signalement de sécurité

Si vous découvrez un problème de sécurité dans ce dépôt ou sur le site APPIX, merci de ne pas publier d’informations exploitables dans une issue publique.

Contactez l’éditeur à l’adresse **zumra-gokhan@outlook.fr** avec :
- une description claire du problème ;
- les étapes pour le reproduire ;
- l’impact observé et, si possible, une preuve non destructive.

N’incluez pas de données personnelles de visiteurs dans votre signalement. Une réponse et un délai de correction ne peuvent pas être garantis, mais les signalements seront examinés de bonne foi.
